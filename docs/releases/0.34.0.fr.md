## Nouveautés
- **Tri et filtres dans Parcourir les jeux.** Triez par Populaires, Les plus récents, Mis à jour récemment, Le Plus D'étoiles GitHub ou A-Z. Quatre interrupteurs affinent la liste : **Installation Facile**, **Multijoueur**, **Tourne Très Bien** et **Masquer Les Jeux Assistés Par IA**.
- **Comment Ça Tourne.** Après une partie, Decomp Buddy demande comment le jeu a tourné. Un clic suffit. Une note ainsi que le processeur, la carte graphique et la mémoire de votre ordinateur sont facultatifs, et vous voyez d'abord exactement ce qui sera envoyé. La page de chaque jeu montre ce que les joueurs ont signalé. La question se désactive dans les Paramètres avec **Demander Comment Ça A Tourné Après Avoir Joué**.
- **Kirby AI.** Une zone de questions : demandez à quoi jouer, ce qu'il faut pour un jeu ou comment l'installer. Kirby répond à partir du catalogue de Decomp Buddy. Les questions ne sont pas enregistrées et leur nombre est limité par heure.
- **Plus d'informations sur la page de chaque jeu :** Sortie, Téléchargements, Version et Étoiles GitHub en un coup d'œil, une carte **Comment L'installer** avec ce que vous apportez et le premier lancement, la mention **Assisté Par IA** quand le projet l'indique, et les autres portages et Dans Le Même Genre présentés avec leurs jaquettes.
- **Mode Big Picture.** Le Mode Canapé change de nom et gagne un bouton en haut à droite de chaque écran.
- **La recherche trouve un jeu par ses autres noms,** comme son titre dans une autre langue ou un nom régional.
- **Un nouveau logo raton laveur et une nouvelle apparence.**

## Améliorations
- Les jaquettes s'affichent en entier au lieu d'être recadrées en carré.
- Steam Deck dans « Fonctionne sur » liste aussi les jeux qui ont une version Linux.
- Un jeu reste listé après la suppression de son projet, tant que Decomp Buddy conserve une copie analysée de son téléchargement.
- Des projets hébergés sur d'autres sites de code peuvent être ajoutés.

## Corrections
- Redémarrer pour mettre à jour installe la mise à jour quand Continuer En Arrière-Plan est activé, et vous prévient si une installation échoue.
