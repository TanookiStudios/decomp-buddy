## 新機能
- **「選択したゲームをダウンロード」。** ゲームを参照で選んで押すだけです。Decomp Buddy がすでに持っているインストール手順を使い、このコンピューター用にすぐ準備するので、読む・貼り付ける・選ぶ必要はありません。各ゲームの自分のコピーを選んで **「ゲームを準備」** を押すと、最後の画面で各ゲームに **「プレイ」** と **「フォルダーを開く」** ボタンが表示されます。リンクの貼り付けやスマートフォン・ヘッドセット向けには、サイドバーの「GitHubからインストール」を引き続き使えます。
- **インストール済みゲームの各ゲームに3つのボタン：** プレイ、フォルダーを開く、ゲームをアンインストール。セーブ、Mod、アップデートなどは **「詳細…」** にあります。
- **「ゲームをアンインストール」** は最初に確認し、次にゲームファイルの扱いを聞きます。**「ROMを削除」** はゲームと一緒にゴミ箱へ、**「ROMを安全に移動」** は Decomp Buddy の初回起動時か設定で選んだフォルダーに保管します。ゲームのフォルダーはゴミ箱に移動するので、元に戻せます。
- **コンソール向け移植。** Xbox 360、Switch、Wii U、PS Vita、3DS などのコンソール向けホームブリュー移植と、コンソール上で動くエミュレーターが「ゲームを参照」に加わりました。「実行対象」でコンソールを選べます。**「Xbox 360用にダウンロード」**（またはそのゲームのコンソール）は、ウイルスチェック済みのファイルをダウンロードして Console Games フォルダーに展開し、プロジェクトのコンソールへのコピー手順を添えてフォルダーを開きます。Decomp Buddy 自体はコンソールにインストールできません。
- **ゲームは Decomp Buddy 自身のコピーからダウンロードされます。** GitHub などからプロジェクトが削除され続けているため、Decomp Buddy は各ゲームのファイルの独自コピーを保管し、そこからダウンロードするようになりました。各ファイルは引き続きマルウェアチェック済みのファイルと照合され、こちらのコピーに届かない場合はプロジェクト自身のダウンロードが使われます。
