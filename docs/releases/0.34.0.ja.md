## 新機能
- **「ゲームを参照」の並べ替えと絞り込み。** 人気、最新、最近更新、GitHub スターが多い順、A-Z で並べ替えられます。4つのスイッチで一覧を絞り込めます：**かんたんセットアップ**、**マルチプレイ**、**快適に動く**、**AI 補助のゲームを隠す**。
- **動作の様子。** プレイ後、Decomp Buddy がゲームの動作を尋ねます。クリック1回で答えられます。メモと、コンピューターのプロセッサー・グラフィックカード・メモリは任意で、送信される内容は事前にすべて確認できます。各ゲームのページにプレイヤーの報告が表示されます。この質問は設定の **「プレイ後に動作の様子を尋ねる」** でオフにできます。
- **Kirby AI。** 質問ボックスです。何を遊ぶか、ゲームに何が必要か、セットアップ方法を尋ねられます。Kirby は Decomp Buddy のカタログから答えます。質問は保存されず、1時間あたりの回数に上限があります。
- **各ゲームのページがより詳しく：** リリース日、ダウンロード数、バージョン、GitHub スターをひと目で確認でき、用意するものと初回起動をまとめた **「セットアップ方法」** カード、プロジェクトが明記している場合の **「AI を補助に使用」** 表示、ほかの移植版と「似たゲーム」のパッケージ画像表示が加わりました。
- **Big Picture モード。** カウチモードの名前が変わり、すべての画面の右上にボタンが付きました。
- **検索は別名でもゲームを見つけます。** 別の言語でのタイトルや地域ごとの名前などです。
- **新しいアライグマのロゴと新しいデザイン。**

## 改善
- パッケージ画像が正方形に切り抜かれず、全体が表示されます。
- 「実行対象」の Steam Deck に、Linux 版のあるゲームも表示されます。
- プロジェクトが削除されても、Decomp Buddy がチェック済みのダウンロードのコピーを持っている限り、ゲームは一覧に残ります。
- より多くのコードサイトでホストされているプロジェクトを追加できます。

## 修正
- 「バックグラウンドで動かす」がオンでも「更新するために再起動」でアップデートがインストールされ、インストールに失敗した場合は通知されます。
