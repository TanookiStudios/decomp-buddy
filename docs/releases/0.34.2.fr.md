## Corrigé
- Sur un Steam Deck, ou tout écran peu haut, la recherche et les filtres ne prennent plus l'essentiel de « Parcourir les jeux ». C'est maintenant toute la page qui défile : ils s'écartent et les jeux remplissent l'écran. Merci au joueur qui nous l'a signalé.

## Nouveau
- « Bientôt disponible » permet maintenant de télécharger le code source que nous avons sauvegardé d'un projet supprimé, comme Leonida. C'est du code pour les développeurs, pas un jeu jouable.
