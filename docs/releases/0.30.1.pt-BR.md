## Melhorias
- Capas para muitos mais jogos, com uma correspondência de títulos mais inteligente. Quando dois jogos diferentes têm o mesmo nome, o Decomp Buddy deixa a capa em branco em vez de adivinhar.
- Versões para Windows com "-PC-" no nome são reconhecidas como downloads do Windows.
## Correções
- Verificação de malware: uma verificação que estoura o tempo não conta mais como alerta, e downloads que chegam corrompidos são tentados de novo.
