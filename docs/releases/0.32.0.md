## New
- **Install When Online:** set up a game with no internet and it waits in Installed Games, then installs by itself as soon as you're back online.
- **Save All Covers For Offline** in Settings: every cover on your computer at once (about 200 MB), so Browse keeps its pictures with no internet.
## Better
- Browse opens in a moment, even the very first time: Decomp Buddy downloads one finished catalog, covers included, instead of building it on your computer. A copy comes inside the app, so a computer that has never been online still has every game to look through.
- Offline or on bad Wi-Fi, Browse and Coming Soon open on their saved lists right away and update quietly when the internet answers. Decomp Buddy says how old the list is.
- Covers are kept at the size the app shows them, so they load faster and take a fifth of the space.
## Fixed
- Opening Decomp Buddy no longer uses up GitHub's hourly lookup limit, so a new computer can set games up straight away.
