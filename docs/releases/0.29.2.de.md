## Neu
- **Warten Auf Einen Port:** Decomps, die noch niemand auf dem Computer spielen kann, bekommen einen eigenen Tab und wandern von selbst in den Katalog, sobald man sie spielen kann.
## Verbessert
- Der Katalog zeigt nur Spiele, die du wirklich auf dem Computer spielen kannst.
