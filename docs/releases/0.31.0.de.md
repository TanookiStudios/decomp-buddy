## Neu
- **Neuigkeiten:** Nach einem Update zeigt Decomp Buddy, was sich geändert hat, in deiner Sprache. Alle Versionen sind außerdem unter decompbuddy.com/changelog aufgelistet.
- Eine Seite **iPhone-App** im Menü, für Decomp Buddy Remote, unsere iPhone-App (demnächst).
- **Mit Decomp Buddy Installieren:** Jedes Spiel auf decompbuddy.com hat einen Installieren-Knopf, der das Spiel direkt hier öffnet, bereit für deine Spieldatei.
- **Sicherheitsbericht** bei jedem Spiel: wann sein Download geprüft wurde, wer ihn hochgeladen hat, seine Lizenz und wie lange es das Konto des Projekts gibt.
- **Die Beste Version Für Dich:** Wenn Spieler sagen, dass die neueste Version eines Spiels nicht startet, installiert Decomp Buddy die letzte Version, die gut lief, bis eine neuere erscheint.
- **Benachrichtige Mich** bei Demnächst-Spielen: Decomp Buddy sagt dir an dem Tag Bescheid, an dem eines spielbar wird, und setzt es auf eine Liste Jetzt Spielbar. Nichts wird irgendwohin gesendet.
- **Installations-Doktor:** Wenn ein Spiel nicht startet, prüft er die üblichen Gründe (fehlende Dateien, die falsche Spieldatei, ein Programm ohne Ausführungsrecht, ein Mac, der es blockiert, fehlende Windows-Teile, Grafikfehler) und bietet für jede Lösung einen Knopf an.
- **Was Es Bietet:** Abzeichen für 60 FPS, Breitbild, HD, Raytracing, Mods, Online-Spiel und Lokaler Mehrspieler, jedes aus der README des Projekts selbst zitiert, mit einem Filter in Spiele durchsuchen.
- **Findet deine Steam-, GOG- und Epic-Spiele:** PC-Neuauflagen wie Fallout 2 Community Edition holen sich die nötigen Dateien aus deiner vorhandenen Kopie. Sie werden kopiert, nie verschoben, also läuft das Spiel in Steam weiter.
## Verbessert
- Wenn GitHub begrenzt, wie viele Abfragen deine Internetverbindung machen darf, sagen die Spielseiten das in einfachen Worten und erklären, wie du es mit einem kostenlosen GitHub-Token behebst.
- Jeder Spielordner hat jetzt eine **About This Game.txt** mit Version, Entwickler und der Seite für Updates, damit ein auf einen anderen Computer kopierter Ordner noch sagt, was er ist.
## Behoben
- Auf manchen Spielseiten stand eine Fehlermeldung von GitHub, wo die Beschreibung des Projekts hätte stehen sollen.
- GitLab-Spiele verschwinden nicht mehr versehentlich aus dem Katalog.
- Zwei Versionen desselben Spiels gleichzeitig einzurichten scheitert nicht mehr beim zweiten: Eine Spieldatei, die beide brauchen, wird kopiert statt verschoben.
## Entfernt
- Die 48-Stunden-Wartezeit für neue Spielversionen. Eine neue Version kommt an, sobald sie die Schadsoftware-Prüfung und die Prüfung des Uploaders bestanden hat.
