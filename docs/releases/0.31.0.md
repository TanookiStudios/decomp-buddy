## New
- **What's New:** after an update, Decomp Buddy shows what changed, in your language. Every version is also listed at decompbuddy.com/changelog.
- An **iPhone App** page in the menu, for Decomp Buddy Remote, our iPhone app (coming soon).
- **Install With Decomp Buddy:** every game on decompbuddy.com has an Install button that opens the game right here, ready for your game file.
- **Safety Report** on every game: when its download was scanned, who uploaded it, its license, and how long the project's account has existed.
- **Best Version For You:** if players say a game's newest version doesn't start, Decomp Buddy installs the last version that ran well, until a newer one comes out.
- **Notify Me** on Coming Soon games: Decomp Buddy tells you the day one can be played, and puts it on a Now Playable list. Nothing is sent anywhere.
- **Install Doctor:** when a game won't start, it checks the usual reasons (missing files, the wrong game file, a program that isn't allowed to run, a Mac blocking it, missing Windows parts, graphics errors) and offers a button for each fix.
- **What It Adds:** badges for 60 FPS, Widescreen, HD, Ray Tracing, Mods, Online Play and Local Multiplayer, each one quoted from the project's own README, with a filter in Browse.
- **Finds your Steam, GOG and Epic games:** PC remakes like Fallout 2 Community Edition fill in the files they need from the copy you already own, copied and never moved, so the game still works in Steam.
## Better
- When GitHub limits how many lookups your internet connection can make, game pages say so in plain words, and how to fix it with a free GitHub token.
- Every game folder now has an **About This Game.txt** that says which version it is, who made it and where its updates come from, so a folder copied to another computer still says what it is.
## Fixed
- Some game pages showed an error message from GitHub where the project's description should be.
- GitLab games no longer drop out of the catalog by mistake.
- Setting up two versions of the same game at once no longer fails on the second one: a game file both of them use is copied instead of moved.
## Removed
- The 48-hour wait for new game versions. A new version arrives as soon as it passes the malware scan and the uploader check.
