## Corrigido
- Alguns jogos continuavam mostrando Atualizar logo depois de atualizar. Eles eram comparados com a versão de outra plataforma. Agora cada jogo é comparado com a versão que de fato é instalada no seu computador. Obrigado ao jogador que nos avisou.
- O Decomp Buddy faz muito menos trabalho ao abrir. As capas carregam conforme você rola, não as 4.600 de uma vez, e algumas não são mais reduzidas de novo a cada abertura. Nos nossos testes, a abertura caiu de uns 46 segundos de trabalho do computador para uns 4, e a memória de mais de 2 GB para menos de 1 GB.
- Com Continuar Rodando Em Segundo Plano ligado, fechar a janela agora só a esconde, então abrir de novo pela bandeja é instantâneo em vez de uma abertura completa.
- Escolher uma cor de destaque nas Configurações agora muda todos os botões, não só o principal. Antes a maioria continuava rosa. Obrigado ao jogador que nos avisou.

## Novo
- Mover Para Outra Pasta, no menu Mais… de cada jogo instalado: move o jogo inteiro, com os saves que estiverem dentro, para qualquer pasta, até em outro disco. Ele continua em Jogos Instalados.
- Configurações → Abrir Em: o app pode abrir em Jogos Instalados em vez de Procurar Jogos.
- Cada cartão de jogo agora tem os links Página Do Projeto e Novidades. Eles também estão no menu Mais… de cada jogo instalado.
- Configurações → Pasta De Atalhos: escolha onde o Atalho Na Área De Trabalho coloca o ícone de cada jogo, em vez de sempre na área de trabalho.
- Configurações → Guardar Versões Antigas: guarde as 2 últimas (o padrão), só a última, ou nenhuma para economizar espaço. Seus saves continuam sendo copiados antes de cada atualização.
