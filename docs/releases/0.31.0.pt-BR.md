## Novo
- **Novidades:** depois de uma atualização, o Decomp Buddy mostra o que mudou, no seu idioma. Todas as versões também estão listadas em decompbuddy.com/changelog.
- Uma página **App Para iPhone** no menu, para o Decomp Buddy Remote, nosso app para iPhone (em breve).
- **Instalar Com O Decomp Buddy:** cada jogo no decompbuddy.com tem um botão de instalar que abre o jogo aqui mesmo, pronto para o seu arquivo do jogo.
- **Relatório De Segurança** em cada jogo: quando o download foi verificado, quem o enviou, a licença e há quanto tempo a conta do projeto existe.
- **A Melhor Versão Para Você:** se os jogadores disserem que a versão mais nova de um jogo não abre, o Decomp Buddy instala a última versão que funcionou bem, até sair uma mais nova.
- **Me Avise** nos jogos de Em Breve: o Decomp Buddy avisa no dia em que der para jogar e coloca o jogo na lista Já Dá Para Jogar. Nada é enviado para lugar nenhum.
- **Doutor De Instalação:** quando um jogo não abre, ele verifica os motivos de sempre (arquivos faltando, o arquivo do jogo errado, um programa sem permissão para executar, um Mac bloqueando, partes do Windows faltando, erros de gráficos) e oferece um botão para cada correção.
- **O Que Traz De Novo:** selos de 60 FPS, Widescreen, HD, Ray Tracing, Mods, Jogo Online e Multijogador Local, cada um citado do próprio README do projeto, com um filtro em Procurar Jogos.
- **Encontra seus jogos da Steam, GOG e Epic:** recriações para PC como Fallout 2 Community Edition pegam os arquivos de que precisam da cópia que você já tem. Eles são copiados, nunca movidos, então o jogo continua funcionando na Steam.
## Melhorias
- Quando o GitHub limita quantas consultas a sua conexão de internet pode fazer, as páginas dos jogos avisam isso em palavras simples, e explicam como resolver com um token gratuito do GitHub.
- Toda pasta de jogo agora tem um **About This Game.txt** dizendo a versão, quem fez e de onde vêm as atualizações, para que uma pasta copiada para outro computador ainda diga o que é.
## Correções
- Algumas páginas de jogos mostravam uma mensagem de erro do GitHub no lugar da descrição do projeto.
- Os jogos do GitLab não somem mais do catálogo por engano.
- Configurar duas versões do mesmo jogo ao mesmo tempo não falha mais na segunda: um arquivo de jogo usado pelas duas é copiado em vez de movido.
## Removido
- A espera de 48 horas por novas versões dos jogos. Uma nova versão chega assim que passa pela verificação de malware e pela checagem de quem a publicou.
