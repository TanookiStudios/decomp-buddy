## Nouveautés
- **Télécharger les jeux sélectionnés.** Choisissez des jeux dans Parcourir les jeux et appuyez dessus. Decomp Buddy les prépare tout de suite pour cet ordinateur avec les étapes d'installation qu'il a déjà : rien à lire, coller ou choisir. Choisissez votre propre copie de chaque jeu, appuyez sur **Préparer les jeux**, et le dernier écran donne à chaque jeu un bouton **Jouer** et un bouton **Ouvrir le dossier**. Installer depuis GitHub reste dans la barre latérale pour coller des liens et pour les téléphones et casques.
- **Jeux installés affiche trois boutons sur chaque jeu :** Jouer, Ouvrir le dossier et Désinstaller le jeu. Sauvegardes, mods, mises à jour et le reste sont sous **Plus…**.
- **Désinstaller le jeu** demande d'abord, puis ce qu'il faut faire de votre fichier de jeu : **Supprimer la ROM** l'envoie à la corbeille avec le jeu, et **Mettre la ROM à l'abri** la garde dans un dossier que vous choisissez au premier lancement de Decomp Buddy ou dans les Paramètres. Le dossier du jeu va à la corbeille, vous pouvez donc encore le récupérer.
- **Portages pour consoles.** Les portages homebrew pour Xbox 360, Switch, Wii U, PS Vita, 3DS et d'autres consoles sont dans Parcourir les jeux, avec les émulateurs faits pour tourner sur une console. Choisissez une console dans Fonctionne sur. **Télécharger pour Xbox 360** (ou la console du jeu) télécharge le fichier vérifié contre les virus, le décompresse dans un dossier Console Games avec les étapes du projet pour le copier sur votre console, et ouvre le dossier. Decomp Buddy ne peut pas installer sur une console lui-même.
- **Les jeux se téléchargent depuis la copie de Decomp Buddy.** Comme des projets continuent d'être retirés de GitHub et d'autres hébergeurs, Decomp Buddy garde maintenant sa propre copie des fichiers de chaque jeu et les télécharge depuis celle-ci. Chaque fichier est toujours comparé à celui qui a été analysé contre les logiciels malveillants, et si notre copie est injoignable, le téléchargement du projet est utilisé à la place.
