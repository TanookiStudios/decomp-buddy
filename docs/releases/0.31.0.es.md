## Nuevo
- **Novedades:** después de una actualización, Decomp Buddy muestra qué cambió, en tu idioma. Todas las versiones también aparecen en decompbuddy.com/changelog.
- Una página **App Para iPhone** en el menú, para Decomp Buddy Remote, nuestra app para iPhone (próximamente).
- **Instalar Con Decomp Buddy:** cada juego en decompbuddy.com tiene un botón de instalar que abre el juego aquí mismo, listo para tu archivo del juego.
- **Informe De Seguridad** en cada juego: cuándo se analizó su descarga, quién la subió, su licencia y cuánto tiempo lleva la cuenta del proyecto.
- **La Mejor Versión Para Ti:** si los jugadores dicen que la versión más nueva de un juego no arranca, Decomp Buddy instala la última versión que funcionó bien, hasta que salga una más nueva.
- **Avísame** en los juegos de Próximamente: Decomp Buddy te dice el día en que uno se puede jugar y lo pone en una lista de Ya Se Puede Jugar. No se envía nada a ningún sitio.
- **Doctor De Instalación:** cuando un juego no arranca, revisa los motivos habituales (archivos que faltan, el archivo del juego equivocado, un programa sin permiso para ejecutarse, un Mac que lo bloquea, partes de Windows que faltan, errores de gráficos) y ofrece un botón para cada arreglo.
- **Lo Que Añade:** insignias de 60 FPS, Pantalla Panorámica, HD, Trazado De Rayos, Mods, Juego En Línea y Multijugador Local, cada una citada del propio README del proyecto, con un filtro en Explorar juegos.
- **Encuentra tus juegos de Steam, GOG y Epic:** las versiones rehechas para PC, como Fallout 2 Community Edition, toman los archivos que necesitan de la copia que ya tienes. Se copian y nunca se mueven, así que el juego sigue funcionando en Steam.
## Mejoras
- Cuando GitHub limita cuántas consultas puede hacer tu conexión a internet, las páginas de los juegos lo explican con palabras sencillas, junto con cómo arreglarlo con un token gratuito de GitHub.
- Cada carpeta de juego tiene ahora un **About This Game.txt** que indica la versión, quién lo hizo y de dónde vienen sus actualizaciones, así una carpeta copiada a otra computadora sigue diciendo qué es.
## Correcciones
- Algunas páginas de juegos mostraban un mensaje de error de GitHub donde debía ir la descripción del proyecto.
- Los juegos de GitLab ya no desaparecen del catálogo por error.
- Instalar dos versiones del mismo juego a la vez ya no falla en la segunda: un archivo de juego que usan las dos se copia en lugar de moverse.
## Eliminado
- La espera de 48 horas para las versiones nuevas de los juegos. Una versión nueva llega en cuanto pasa el análisis de malware y la verificación de quien la sube.
