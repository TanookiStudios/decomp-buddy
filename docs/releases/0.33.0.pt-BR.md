## Novo
- **Baixar jogos selecionados.** Escolha jogos em Procurar jogos e pressione. O Decomp Buddy prepara tudo para este computador na hora, com os passos de instalação que já tem, então não há nada para ler, colar ou escolher. Escolha sua própria cópia de cada jogo, pressione **Preparar jogos** e a última tela dá a cada jogo um botão **Jogar** e um **Ir para a pasta**. Instalar do GitHub continua na barra lateral para colar links e para celulares e headsets.
- **Jogos instalados tem três botões em cada jogo:** Jogar, Ir para a pasta e Desinstalar jogo. Saves, mods, atualizações e o resto ficam em **Mais…**.
- **Desinstalar jogo** pergunta primeiro e depois o que fazer com seu arquivo de jogo: **Excluir ROM** o envia para a lixeira junto com o jogo, e **Tirar a ROM com segurança** o guarda numa pasta que você escolhe ao abrir o Decomp Buddy pela primeira vez ou nas Configurações. A pasta do jogo vai para a lixeira, então você ainda pode recuperá-la.
- **Ports para consoles.** Ports homebrew para Xbox 360, Switch, Wii U, PS Vita, 3DS e outros consoles estão em Procurar jogos, junto com emuladores feitos para rodar num console. Escolha um console em Funciona em. **Baixar para Xbox 360** (ou o console daquele jogo) baixa o arquivo verificado contra vírus, descompacta numa pasta Console Games com os passos do projeto para copiá-lo para o seu console e abre a pasta. O Decomp Buddy não consegue instalar num console sozinho.
- **Os jogos são baixados da cópia do próprio Decomp Buddy.** Como projetos continuam sendo removidos do GitHub e de outros sites, o Decomp Buddy agora guarda sua própria cópia dos arquivos de cada jogo e baixa de lá. Cada arquivo continua sendo comparado com o que foi verificado contra malware e, se a nossa cópia não estiver disponível, o download do próprio projeto é usado no lugar.
