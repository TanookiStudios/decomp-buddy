## 新機能
- **ダウンロードはマルウェアスキャンされます。** 「マルウェアスキャン済み」と表示されたゲームは、スキャンしたファイルそのものだけをインストールします。プロジェクトがファイルを差し替えた場合は、新しいスキャンを待ちます。
- **新しいバージョンは48時間待ちます。** また、誰かに届く前に、そのプロジェクトがいつも使っている投稿者からのものである必要があります。
- **自動アップデート：** スケジュールに合わせて確認し、アップデートを自動でインストールします（セーブデータは先にバックアップ）。トレイに常駐し、パソコンの起動と同時に開始できます。ゲームごとに、自動アップデートのオン／オフ、「このバージョンをスキップ」、「好きなバージョンを選ぶ」を選べます。
- **Meta QuestとAndroid：** ヘッドセット向けとスマホ向けのポートをUSBでインストールできます。
- **LinuxとSteam DeckでWindowsゲーム**を、Proton、umu-run、Wineのどれかで動かせます。ゲームごとに選べます。
- **動作はどうでしたか？** 「よく動く」「問題あり」「動かない」を選べて、自分と同じ種類のコンピューターの集計も見られます。「自分と同じ種類のコンピューターでよく動く」フィルターと「壊れたダウンロードを報告」もあります。
- **AI の使用ラベル**（AI 不使用、AI を補助に使用、AI で作成）。プロジェクト自身のREADMEの記載だけをもとに、引用で表示します。
- **Thunderstoreのmod**を、依存関係も含めて、N64 RecompのゲームとHarbourMastersのポート向けに使えます。成人向けのmodは、選ばない限り表示されません。
- Codebergのプロジェクト、ARMコンピューター、そしてより多くのダウンロード形式（.deb、.run、.msi、AppImage、単体のプログラム）に対応しました。
- **すべての画面でコントローラーが使えます。** ボタンの割り当て変更、Nintendo配列、テキスト欄でのSteam Deckのキーボードにも対応しました。
- **自分好みに：** アクセントカラー、背景の画像と音楽、グリッド・リスト・コンパクトのレイアウト、50〜200%の表示サイズ。
- **キオスクモード**は、アーケード筐体や共用のパソコン向けで、終了するにはPINが必要です。
- 「ゲームを削除」（ゴミ箱へ移動）、ゲームの名前変更・タグ付け・非表示、デスクトップショートカット、ゲームが起動しないときのログ、ニュースバナー、GitHubの問い合わせカウンターを追加しました。
