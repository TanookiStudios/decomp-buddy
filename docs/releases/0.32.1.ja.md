## 新機能
- **Mac と Linux の「ここにビルド」が CMake と Ninja を自動で用意します。** どちらかが足りない場合、Decomp Buddy が公式版を一度だけダウンロードし、専用のフォルダに保存します。ほかのツールが必要なゲームもあり、その場合はビルド画面に表示されます。
## 修正
- Linux と Intel Mac で、.zip や .7z 形式のゲームを展開できなかった問題を修正し、インストールできるようにしました。
- お使いのコンピュータ向けのバージョンがないゲームを選ぶと、「インストール手順がまだない」ではなく、その旨と対応しているコンピュータを表示するようにしました。
