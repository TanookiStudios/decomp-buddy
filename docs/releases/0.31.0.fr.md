## Nouveautés
- **Nouveautés :** après une mise à jour, Decomp Buddy affiche ce qui a changé, dans votre langue. Toutes les versions sont aussi listées sur decompbuddy.com/changelog.
- Une page **App iPhone** dans le menu, pour Decomp Buddy Remote, notre app iPhone (bientôt disponible).
- **Installer Avec Decomp Buddy :** chaque jeu sur decompbuddy.com a un bouton d'installation qui ouvre le jeu ici même, prêt pour votre fichier de jeu.
- **Rapport De Sécurité** sur chaque jeu : quand son téléchargement a été analysé, qui l'a mis en ligne, sa licence et depuis quand existe le compte du projet.
- **La Meilleure Version Pour Vous :** si les joueurs disent que la version la plus récente d'un jeu ne démarre pas, Decomp Buddy installe la dernière version qui fonctionnait bien, jusqu'à la sortie d'une plus récente.
- **Me Prévenir** sur les jeux Bientôt disponibles : Decomp Buddy vous dit le jour où l'un d'eux devient jouable et l'ajoute à une liste Maintenant Jouable. Rien n'est envoyé nulle part.
- **Docteur D'Installation :** quand un jeu ne démarre pas, il vérifie les causes habituelles (fichiers manquants, mauvais fichier de jeu, programme qui n'a pas le droit de s'exécuter, Mac qui le bloque, composants Windows manquants, erreurs graphiques) et propose un bouton pour chaque réparation.
- **Ce Qu'il Ajoute :** des badges 60 FPS, Écran Large, HD, Ray Tracing, Mods, Jeu En Ligne et Multijoueur Local, chacun cité depuis le README du projet lui-même, avec un filtre dans Parcourir les jeux.
- **Trouve vos jeux Steam, GOG et Epic :** les refontes PC comme Fallout 2 Community Edition récupèrent les fichiers dont elles ont besoin dans la copie que vous possédez déjà. Ils sont copiés, jamais déplacés, donc le jeu fonctionne toujours dans Steam.
## Améliorations
- Quand GitHub limite le nombre de requêtes que votre connexion internet peut faire, les pages de jeu l'expliquent avec des mots simples, ainsi que la façon d'y remédier avec un jeton GitHub gratuit.
- Chaque dossier de jeu contient maintenant un **About This Game.txt** qui indique la version, qui l'a créé et d'où viennent ses mises à jour, pour qu'un dossier copié sur un autre ordinateur dise toujours ce qu'il est.
## Corrections
- Certaines pages de jeu affichaient un message d'erreur de GitHub à la place de la description du projet.
- Les jeux GitLab ne disparaissent plus du catalogue par erreur.
- Installer deux versions du même jeu en même temps n'échoue plus sur la seconde : un fichier de jeu utilisé par les deux est copié au lieu d'être déplacé.
## Supprimé
- L'attente de 48 heures pour les nouvelles versions des jeux. Une nouvelle version arrive dès qu'elle passe l'analyse antimalware et la vérification de la personne qui l'a publiée.
