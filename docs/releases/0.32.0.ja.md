## 新機能
- **オンライン時にインストール:** インターネットがないときにゲームをセットアップすると、インストール済みゲームで待機し、オンラインに戻ると自動でインストールされます。
- 設定に**オフライン用にすべてのカバーを保存**を追加: すべてのカバーを一度にパソコンへ保存(約200MB)。インターネットがなくてもゲームを参照に画像が表示されます。
## 改善
- ゲームを参照が、初回でもすぐに開くようになりました。パソコン上でカタログを組み立てるのではなく、カバー込みの完成したカタログを1つダウンロードします。アプリにもコピーが入っているので、一度もネットにつないでいないパソコンでもすべてのゲームを見られます。
- オフラインや電波の悪いWi-Fiでも、ゲームを参照と近日登場は保存済みのリストをすぐに開き、インターネットが応答したら静かに更新します。リストがいつのものかも表示します。
- カバーはアプリで表示するサイズで保存されるので、読み込みが速く、容量は5分の1になりました。
## 修正
- Decomp Buddyを開くだけでGitHubの1時間あたりの回数制限を使い切ることがなくなり、新しいパソコンでもすぐにゲームをセットアップできます。
