## New
- **Downloads are scanned for malware**, and a game marked Scanned For Malware only ever installs the exact file that was scanned. If a project swaps the file, it waits for a new scan.
- **New versions wait 48 hours** and must come from the project's usual uploader before anyone gets them.
- **Auto Update:** check on a schedule, install updates by themselves (saves backed up first), keep running in the tray, start with your computer. Per game: Auto Update on or off, Skip This Version, Pick Any Version.
- **Meta Quest and Android:** install headset and phone ports over USB.
- **Windows games on Linux and Steam Deck** through Proton, umu-run or Wine, picked per game.
- **How Did It Run?** Runs Well, Has Issues or Doesn't Run, with totals for computers like yours, a Runs Well On Computers Like Mine filter, and Report Broken Download.
- **AI Use labels** (No AI Used, AI-Assisted, Made With AI), only from what the project's own README says, quoted.
- **Thunderstore mods**, with their dependencies, for the N64 Recomp games and HarbourMasters ports. Adult mods are hidden unless you choose.
- Codeberg projects, ARM computers, and more download types (.deb, .run, .msi, AppImage, single programs).
- **Controllers on every screen**, button remapping, Nintendo layout, and the Steam Deck keyboard in text boxes.
- **Make It Yours:** accent color, background picture and music, Grid, List or Compact layouts, and Interface Size from 50 to 200%.
- **Kiosk Mode** for arcade cabinets and shared computers, with a PIN to leave.
- Remove A Game (to the Trash), rename, tag and hide games, desktop shortcuts, a log when a game won't start, a news banner, and a GitHub lookup counter.
## Fixed
- 164 games whose Update reinstalled the same old version.
