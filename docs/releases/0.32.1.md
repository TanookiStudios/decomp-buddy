## New
- **Build Here gets CMake and Ninja for you** on Mac and Linux. If either one is missing, Decomp Buddy downloads the official copy once and keeps it in its own folder. Some games still need other tools, and the build screen says which.
## Fixed
- On Linux and Intel Macs, games that come as a .zip or .7z couldn't unpack. They install now.
- Picking a game with no version for your computer now says so and names the computers it runs on, instead of saying it has no install steps yet.
