## Améliorations
- Des jaquettes pour beaucoup plus de jeux, avec une reconnaissance des titres plus intelligente. Quand deux jeux différents portent le même nom, Decomp Buddy laisse la jaquette vide plutôt que de deviner.
- Les versions Windows dont le nom contient « -PC- » sont reconnues comme des téléchargements Windows.
## Corrections
- Analyse antimalware : une analyse qui dépasse le temps imparti n'est plus comptée comme un signalement, et les téléchargements qui arrivent corrompus sont relancés.
