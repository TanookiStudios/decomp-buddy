## New
- **Download Selected Games.** Pick games in Browse and press it. Decomp Buddy gets them ready for this computer right away, using the install steps it already has, so there's nothing to read, paste or choose. Choose your own copy of each game, press **Prepare Games**, and the last screen gives every game a **Play Game** and a **Go To Folder** button. Install From GitHub is still in the sidebar for pasting links and for phones and headsets.
- **Installed Games has three buttons on every game:** Play Game, Go To Folder and Uninstall Game. Saves, mods, updates and the rest are under **More…**.
- **Uninstall Game** asks first, then asks what to do with your game file: **Delete Rom** sends it to the Trash with the game, and **Move Rom Out Safely** keeps it in a folder you choose when you first start Decomp Buddy or in Settings. The game's folder goes to the Trash, so you can still get it back.
- **Console ports.** Homebrew ports for the Xbox 360, Switch, Wii U, PS Vita, 3DS and other consoles are in Browse, along with emulators made to run on a console. Pick a console under Runs On. **Download For Xbox 360** (or that game's console) downloads the virus-scanned file, unpacks it into a Console Games folder with the project's steps for copying it onto your console, and opens the folder. Decomp Buddy can't install onto a console itself.
- **Games download from Decomp Buddy's own copy.** Because projects keep being removed from GitHub and other hosts, Decomp Buddy now keeps its own copy of every game's files and downloads them from there. Each file is still checked against the one that was scanned for malware, and if our copy can't be reached, the project's own download is used instead.
