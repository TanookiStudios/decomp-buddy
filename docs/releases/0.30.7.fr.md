## Nouveautés
- Le Mode Canapé a une tuile **Obtenir Plus De Jeux**, pour parcourir et installer des jeux sans quitter le Mode Jeu.
## Améliorations
- Le téléchargement pour Steam Deck sort à chaque version, et la version Steam Deck vous prévient quand une plus récente est disponible.
## Corrections
- **Ajouter Decomp Buddy à Steam fonctionne depuis la version Steam Deck.** Avant, le raccourci s'ouvrait sur un écran noir. Si vous l'aviez déjà ajouté, ajoutez-le de nouveau une fois (Paramètres, Ajouter Decomp Buddy à Steam).
- Le raccourci AppImage ne charge plus la surcouche de Steam dans Decomp Buddy, une cause fréquente d'écrans noirs en Mode Jeu.
