## New
- Couch Mode has a **Get More Games** tile, so you can browse and set up games without leaving Gaming Mode.
## Better
- The Steam Deck download comes out with every release, and the Steam Deck version tells you when a newer one is out.
## Fixed
- **Add Decomp Buddy To Steam works from the Steam Deck version.** Before, the shortcut opened to a black screen. If you added it before, add it again once (Settings, Add Decomp Buddy To Steam).
- The AppImage shortcut no longer loads Steam's overlay into Decomp Buddy, a common cause of black screens in Gaming Mode.
