## New
- **Sort and filter Browse.** Sort by Popular, Newest, Recently Updated, Most GitHub Stars or A-Z. Four switches narrow the list: **Easy Setup**, **Multiplayer**, **Plays Great** and **Hide AI-Assisted**.
- **How It Runs.** After you play, Decomp Buddy asks how the game ran. One click answers it. A note and your computer's processor, graphics card and memory are optional, and you see exactly what will be sent first. Every game's page shows what players reported. Turn the question off in Settings with **Ask How It Ran After I Play**.
- **Kirby AI.** A question box: ask what to play, what a game needs, or how to set one up. Kirby answers from Decomp Buddy's own catalog. Questions aren't saved, and there's a limit on how many you can ask in an hour.
- **More on every game's page:** Released, Downloads, Version and GitHub Stars at a glance, a **How To Set Up** card with what you bring and the first start, an **AI-Assisted** label when the project says so, and Other Ports and More Like This shown as box art.
- **Big Picture Mode.** Couch Mode has a new name and a button at the top right of every screen.
- **Search finds a game by its other names,** such as its title in another language or a regional name.
- **A new raccoon logo and a new look.**

## Better
- Box art is shown whole instead of cropped to a square.
- Steam Deck under Runs On also lists games that have a Linux build.
- A game stays listed after its project is removed, as long as Decomp Buddy holds a scanned copy of its download.
- Projects hosted on more code sites can be added.

## Fixed
- Restart To Update installs the update when Keep Running In The Background is on, and tells you if an install fails.
