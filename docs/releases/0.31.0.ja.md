## 新機能
- **更新内容：** アップデート後に、Decomp Buddyが変更点をあなたの言語で表示します。すべてのバージョンは decompbuddy.com/changelog にも一覧があります。
- メニューに、iPhoneアプリ「Decomp Buddy Remote」（近日登場）用の**iPhone アプリ**ページが加わりました。
- **Decomp Buddy でインストール：** decompbuddy.com のすべてのゲームにインストールボタンがあり、押すとこのアプリでゲームが開き、ゲームファイルを選ぶだけになります。
- すべてのゲームに**安全レポート**：ダウンロードがスキャンされた日、アップロードした人、ライセンス、プロジェクトのアカウントの作成時期がわかります。
- **あなたに最適なバージョン：** 最新バージョンが起動しないとプレイヤーから報告があったゲームは、新しいバージョンが出るまで、正常に動いた最後のバージョンをインストールします。
- 近日登場のゲームに**お知らせを受け取る**：遊べるようになった日に Decomp Buddy がお知らせし、「遊べるようになりました」の一覧に追加します。どこにも何も送信されません。
- **インストールドクター：** ゲームが起動しないとき、よくある原因（なくなったファイル、間違ったゲームファイル、実行が許可されていないプログラム、Mac によるブロック、足りない Windows の部品、グラフィックのエラー）を確認し、修正ごとにボタンを用意します。
- **追加される機能：** 60 FPS、ワイドスクリーン、HD、レイトレーシング、モッド、オンラインプレイ、ローカルマルチプレイのバッジ。どれもプロジェクト自身の README から引用し、「ゲームを参照」で絞り込めます。
- **Steam・GOG・Epic のゲームを見つけます：** Fallout 2 Community Edition のような PC リメイクは、必要なファイルをお持ちのゲームから自動で用意します。コピーするだけで移動はしないので、Steam のゲームもそのまま遊べます。
## 改善
- GitHubがインターネット接続ごとの問い合わせ回数を制限しているとき、ゲームのページがわかりやすい言葉でそれを伝え、無料のGitHubトークンで解決する方法も案内します。
- すべてのゲームフォルダーに **About This Game.txt** が入り、バージョン、作者、アップデートの入手先がわかるようになりました。別のパソコンにコピーしても何のフォルダーかわかります。
## 修正
- 一部のゲームページで、プロジェクトの説明が入るはずの場所にGitHubのエラーメッセージが表示されていました。
- GitLabのゲームが誤ってカタログから消えることはなくなりました。
- 同じゲームの2つのバージョンを同時にセットアップしても、2つ目が失敗しなくなりました。両方が使うゲームファイルは移動ではなくコピーされます。
## 削除
- 新しいゲームバージョンの48時間の待機を廃止しました。新しいバージョンは、マルウェアスキャンと投稿者の確認を通ればすぐに届きます。
