# Decomp Buddy

This repository only holds Decomp Buddy's installers (see **Releases**). The app itself is at
**[decompbuddy.com](https://decompbuddy.com)**, made by [Tanooki Studios](https://tanookistudios.com).

Decomp Buddy sets up fan-made PC ports, decompilations and recompilations of console games from
your own game files. It never downloads games.

- **Mac:** Apple Silicon and Intel, signed and notarized.
- **Windows:** installer or portable.
- **Linux:** AppImage or .deb.

Downloads: [decompbuddy.com/download](https://decompbuddy.com/download)
