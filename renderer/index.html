Install From GitHub

Paste decomp / recomp GitHub links, or pick them in Browse Games. Read Repos finds out what each game needs, you choose your own game files (archives are fine), Set Up Games builds a ready-to-go folder per game and writes install.html.

Decomp Buddy never downloads games. You supply your own copies; verification checks they're the ones the project needs.

    Phones And Headsets
    Android ports go onto an Android phone or handheld, or a Meta Quest headset, over a USB cable. Set the game up in Install From GitHub with Build For set to Android Phone Or Handheld or Meta Quest, then install it here.
    
    
    
      First: Google's Android Platform-Tools
      
    Decomp Buddy talks to phones and headsets with adb, a free tool from Google (about 16 MB). It comes straight from dl.google.com and is checked against the fingerprint Google publishes.
    
      
      
    Read Google's Terms
    
      
    
    
    
    
    
      Meta Quest: One-Time Setup
      
    Meta's rules say Developer Mode is for developers; using it to sideload games is at your own risk with your Meta account.
    
      
      
        
    1. Make a Meta developer account. You must be 18 or older and verify it with a phone number or a card. Meta's Instructions
      2. 
        
    2. In the Meta Horizon app on your phone, open your headset's settings and turn on Developer Mode.
      3. 
        
    3. Windows only: install Meta's ADB driver. Meta's ADB Driver
      4. 
        
    4. Plug the headset into this computer with a USB-C cable, put it on, and choose Always Allow From This Computer.
      5. 
        
    5. Status: Not Seen
      6. 
      
    
    
    
    
    
      Android Phone Or Handheld: One-Time Setup
      
      
        
    1. Settings → About Phone → tap Build Number seven times, until it says you're a developer. (On some phones Build Number is under Software Information.)
      2. 
        
    2. Settings → Developer Options → turn on USB Debugging. (On some phones Developer Options is under System.)
      3. 
        
    3. Plug it into this computer with a USB cable, unlock it, tick Always Allow From This Computer, and choose Allow.
      4. 
        
    4. Status: Not Seen
      5. 
      
    
      
    Wireless Debugging (no cable) isn't supported yet.

    Some games only come as a Windows version. It uses the Proton builds Steam already has: in Steam, search your Library for "Proton" and install one if none is listed. Each game gets its own Windows setup, so one can't break another, and you can pick a different Proton per game in its More… panel.

    The person behind it
    
      
    About Maddie
    
      
    Maddie is an autistic app developer who builds privacy-focused apps and websites for things she thinks should already exist. When the internet leaves an oddly specific hole in the world, she has a habit of falling into it and eventually climbing back out with a working product.
    
      
    Decomp Buddy is one of those holes. The decomp and recomp scene is doing something remarkable - turning games that were locked to old consoles into real native PC programs - but every project ships with its own build, its own folder rules, its own idea of where your disc image goes. Maddie got tired of reading twenty READMEs to set up twenty games, so she built the thing that reads them for you, checks that the dump you picked is the one the project actually wants, and hands you a folder that just works.
    
      
    Because autism and a few other life complications make traditional employment a particularly bad match, app development is Maddie's full-time job. It has been rewarding, unpredictable, occasionally ridiculous, and one heck of a ride.
    
      
    Decomp Buddy is free. There is no paywall coming, no account to make, and no advertising. You bring your own legally owned games; nothing about you leaves this computer. If it saved you an evening of README archaeology, you can support Maddie's work, and that support is what keeps her building useful, privacy-respecting things the world forgot to make.
